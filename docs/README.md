Продолжение разработки: единственный [CURRENT_WORK_ITEM](../PLANNING/SESSION_STATE.md). [Машинная карта](OUTCOME_MAP.json) сохраняет покрытие 115 исходных требований. Их классы означают намерение, не готовность.

Порядок authority: последнее применимое явное указание пользователя → установленные решения/ограничения → эта редакция и сохранённые requirements → candidate-планы → исторические справки. Историческая attribution отдельных требований неизвестна; общий каталог не считается новым commit всего scope. При конфликте не подменять intent молча.

[История и источники](../PLANNING/HISTORY/README.md). Принятые контракты v1.11, runtime-протоколы и receipts имеют свою область действия; новые документы их не переписывают. UI, представления и Markdown-экспорт временно исключены из работ, а их прежние outcomes не отменены.
