# Цель продукта

**N-PRODUCT-001 — documented intent:** долговременный личный банк полезных материалов, с которым пользователь работает через ChatGPT. Файл, визуал, идея, заметка, текст или результат исследования сохраняются независимо от проекта; позднее их можно найти, связать, использовать и продолжить работу новым чатом.

**N-PRODUCT-002 — explicit clarification:** любые прикладные типы определяются пользователем/конфигурацией. Вакансия, игра, заметка, источник, исследование и коллекция — примеры, а не обязательные встроенные классы. Сущность означает объект банка; объект исследования — роль этого объекта в конкретной работе.

Система обеспечивает осмысленный процесс исследования, различение данных и выводов, метод, provenance и проверку. Приложение обеспечивает устойчивое состояние, операции, валидацию, сохранность и историю. ChatGPT понимает запрос, исследует доступными инструментами и управляет приложением через существующий Туннель. Чат не заменяет постоянное хранилище.

Обязательные границы результата:

- FR-PRODUCT-001: простое сохранение и чтение не требуют фиктивного ResearchRun или обязательного проекта (INT-002, MVP-002).
- FR-PRODUCT-002: сохраняются ID, исходные основания, авторство и история; неизвестное происхождение обозначается неизвестным (INT-009, ANTI-009).
- FR-PRODUCT-003: прикладной тип добавляется определением данных; инфраструктурные операции/валидация могут быть встроены. Это целевая модель, пока не нынешний runtime.
- FR-PRODUCT-004: raw материал, наблюдение, пользовательская/AI-заметка и вычисленный результат различимы; рейтинг не становится истиной (INT-011, ANTI-006).
- FR-PRODUCT-005: повторное исследование сохраняет запуск, метод, membership результатов и сравнимость, не переписывая прошлое (MVP-004…008).

Универсальность не означает одну огромную схему со всеми полями всех областей (ANTI-007). Доменные наборы дают определения и правила поверх общего ядра. Git полезен для истории файлов/кода, но не подменяет атомарное сохранение записей, provenance и ссылки на конкретное состояние данных.

Текущий локальный scope допускает работу при включённом ПК, публичные источники и непубличные собственные идеи. Дополнительные AI-провайдеры сейчас не нужны. Работа над UI, представлениями и экспортом отложена по явному указанию; данные и операции разрешены. Полный исторический MVP не объявлен выполненным и не заменён малым экспериментом.
