# Migration Support

## Current target: v1.11.0

Direct supported migration: **v1.10.x → v1.11.0**.

The migration updates project system-version contracts while preserving existing task route lineage and research history. v1.9 projects should first use the documented v1.9→v1.10 migration path or bootstrap through the current supported baseline process.

Phase 2 adds result/query use-case contracts but does not rewrite historical research data or fabricate result projections.
