# UC25 — Get Research Health

## Procedure

1. Resolve all-research or scoped health request.
2. Request freshness, coverage, comparability and integrity diagnostics from the result-health projection.
3. Return stale/partial/failed/quality flags explicitly.
4. Distinguish research-health findings from reusable-system audit findings.
5. Recommend refresh/repair where needed without performing those commands implicitly.
