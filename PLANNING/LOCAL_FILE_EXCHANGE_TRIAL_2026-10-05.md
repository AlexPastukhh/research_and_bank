## Техническая проба

`EXPERIMENTS/local_file_exchange/probe.py` — изолированный эксперимент со стандартной библиотекой Python.
Он сохраняет синтетическую техническую заметку, затем читает её через отдельную функцию-потребитель и строит disposable catalog.json.
Отчёт не является исследованием, требованиями продукта или production-схемой Bank.

Каждый запуск создаёт новую папку; существующие материалы не перезаписываются.
report.md записывается первым. READY.json с ID и SHA-256 публикуется последним через атомарную замену временного файла.
Потребитель пропускает папки без READY.json и проверяет путь, наличие и хеш отчёта перед чтением.
Маркер не обеспечивает полноценную транзакцию для произвольных изменяемых пакетов.

Запуск из корня:
```powershell
python EXPERIMENTS\local_file_exchange\probe.py demo
python EXPERIMENTS\local_file_exchange\probe.py scan --root EXPERIMENTS\local_file_exchange\data\run-9dd4bc791495
```

Результат первого запуска: PASS.
Материал: `EXPERIMENTS/local_file_exchange/data/run-9dd4bc791495/trial-1041fc0c79db/report.md`.
Проекция: `EXPERIMENTS/local_file_exchange/data/run-9dd4bc791495/catalog.json`.
Проверены чтение полного отчёта, пропуск незавершённой записи, стабильность повторного чтения,
отказ при изменённом содержимом, отсутствующем отчёте и пути за пределами пакета.

## Ограничения и следующая работа

Universal Bank пока не является реализованным приложением. Здесь нет UI, автоматического наблюдения за папкой, полного импорта объектов, версий или конфликтов.
Работоспособность исходной v1.11 этим тестом не перепроверялась; известная проблема tests/TESTS остаётся.
Следующий приёмочный сценарий: сохранение реального исследования с источниками и вложением,
автоматическое появление в интерфейсе, повторное открытие оригинала и сохранение продолжения без дубликатов.
До этого нужно согласовать минимальный контракт локальной записи с MVP и Source/Entity; эксперимент не заменяет их.

GitHub push не выполнялся в рамках этой пробы. Локальное сохранение не означает публикацию или резервное копирование.
Публичность выбранного репозитория относится к отправленным в него файлам; маршрут Commander сам по себе не требует публикации.
Политика приватных материалов, media/backup и критерий перехода на сервер остаются открытыми.
