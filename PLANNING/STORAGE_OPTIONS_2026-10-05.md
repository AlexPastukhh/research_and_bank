# Хранение Bank и доступ из ChatGPT — 2026-10-05

Это исследование вариантов, а не окончательный выбор хранилища. Критерий: удобно сохранить, найти позже, открыть оригинал, передать изображение для визуального анализа и записать результат обратно со связью с источником.

| Вариант | Назначение | Непроверенная часть |
|---|---|---|
| Public GitHub | Система, планы, текстовые результаты и небольшие открытые материалы | Полный путь анализа изображения через выбранное подключение |
| Private GitHub | Проектные файлы с контролем доступа | В текущем подключении пользователь наблюдал отсутствие визуального контекста; иной обработчик не тестировался |
| Dropbox + плагин | Приватные оригиналы, PDF, изображения и результаты | Изображения для модели и write-back; операции плагина пока недоступны в этой сессии |
| Google Drive + плагин | Приватные файлы, Docs/Sheets/Slides | Изображения и запись обычных файлов через конкретное подключение |
| Notion + плагин | Карточки, заметки, связи и каталог | Визуальный анализ вложений; не выбран как основной файловый backend |
| Box + плагин | Приватное файловое хранилище | Изображения, тариф и фактические квоты подключения |
| Собственный плагин Bank | Явные операции сохранения/поиска/получения изображения | Требует разработки и проверки; не является готовым решением |

## Опубликованные квоты сервисов

Эти числа не означают число поручений в ChatGPT: один вызов плагина может обращаться к API несколько раз. Конкретное подключение может иметь дополнительные квоты, а ChatGPT имеет собственный бюджет использования.

| API | Публичная квота |
|---|---|
| GitHub REST | Обычно 5 000 запросов/час с авторизацией; 60/час на IP без неё. Дополнительные search/secondary limits; создание контента обычно до 80 запросов/мин и 500/час. GitHub App installation имеет отдельный механизм квот. |
| Dropbox | Точные численные rate limits не публикуются. Ограничения per-authorization; 429 и Retry-After. Это не безлимитный API. |
| Google Drive | Новая система квот: 325 000 quota units/мин на пользователя в проекте, 1 000 000/мин на проект. files.get — 5, files.list — 100, files.download — 200 units. Старые проекты могут сохранять прежние квоты. Не устанавливает квоту плагина ChatGPT. |
| Notion | 180 запросов/мин на подключение; Business/Enterprise — 600/мин. Дополнительные workspace и MCP-tool limits. |
| Box | Обычно 1 000 запросов/мин на пользователя; uploads 240/мин; search 60/мин и дополнительные ограничения. Месячная API allocation зависит от лицензии. |

У GitHub обычный Git блокирует файлы больше 100 MiB; для более крупных файлов нужен иной путь, например LFS. Размер хранилища, лимиты файлов/передачи и rate limits нужно сравнивать отдельно.

Отдельная численная гарантия количества обращений к готовому Dropbox-плагину из ChatGPT не найдена. Рабочая нагрузка и оставшиеся квоты конкретного аккаунта не измерялись.

## Минимальный эксперимент перед выбором

1. Небольшой PNG/JPEG с деталями, которые нельзя вывести из названия файла; PDF и текстовая заметка.
2. Сохранить в закрытой тестовой папке.
3. В новом чате найти по каталогу/запросу и открыть исходный файл.
4. Описать визуальные детали изображения и сопоставить с оригиналом; текстовый fetch/OCR не считать доказательством visual input.
5. Сохранить анализ обратно, указав устойчивую ссылку/ID оригинала.
6. Записать доступные операции, число вызовов, задержки, ошибки квот и ограничения файлов. Разрешения и публичность не менять ради прохождения теста.
